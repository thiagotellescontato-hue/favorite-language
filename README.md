# Favorite Language

Favorite Language is a client-side Minecraft Fabric mod that adds favorites to the language screen.

It lets you mark your preferred languages with a star and quickly access them using the Favorites button, making it easier to switch between languages without scrolling through the full list every time.

## Features

| Feature | Description |
|---|---|
| ⭐ Favorite Languages | Adds a star button next to languages in the language screen. |
| Quick Access | Use the Favorites button to quickly open your favorite languages. |
| Simple Integration | Keeps the vanilla language screen familiar and easy to use. |
| Client-Side Only | No server installation required. |
| Lightweight | Focused only on improving the language selection screen. |

## How It Works

Open **Options > Language**.

Click the star next to a language to add it to your favorites.

After that, use the **Favorites** button to quickly select your preferred languages.

## Compatibility
